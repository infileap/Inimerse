# Inim OS 总纲

## 一、定义

**Inim OS** 是以 Inimerse 引擎为内核、为 Infiverse 多元宇宙提供安全运行环境的**用户态操作系统**。它既是一个类 POSIX 的脚本操作系统，也是一个宇宙宿主，更是一个桌面即世界的空间化交互环境。

```
一句话：Inim OS 是运行在任意平台之上、以 .im/.inim 为原生可执行格式、
以 Eidos 为对象模型、以 Verse 为宇宙单元、以热修改为进化机制的操作系统。
```

## 三、进程模型

### 3.1 三种进程类型

| 类型 | 实现 | 隔离性 | 用途 |
|---|---|---|---|
| **轻量进程** | `task`（Fiber 协程） | 共享内存 | 系统服务、快速任务 |
| **标准进程** | `thread`（OS 线程） | 共享内存 | 应用主循环 |
| **隔离进程** | `isolate_run` 子进程 | 完全隔离 | 第三方宇宙、不可信代码 |

### 3.2 进程生命周期

```
创建 → 就绪 → 运行 → 阻塞 → 终止
              ↑        ↓
              └── 恢复 ←┘
```

### 3.3 PID 约定

```
PID 1    : init.im         # 系统启动
PID 2    : kernel_task     # 调度器
PID 3    : security_daemon # 安全监控
PID 4    : verse_manager   # 宇宙管理
PID 5    : desktop_layer   # 桌面层
PID 100+ : 用户进程
```

## 四、文件系统

### 4.1 目录树

```
/
├── bin/           # 系统命令（.inim 预编译字节码）
├── usr/bin/       # 用户程序
├── etc/           # 配置（passwd, group, profile）
├── home/          # 用户目录
├── proc/          # 虚拟文件系统（动态生成）
├── dev/           # 设备文件
├── tmp/           # 临时文件
├── var/           # 日志、运行数据
└── mnt/verses/    # 已安装的宇宙
```

### 4.2 可执行文件

| 扩展名 | 内容 | 执行方式 |
|---|---|---|
| `.im` | 文本源码 | 运行时编译执行 |
| `.inim` | 预编译字节码（魔数 `INIM`） | 直接加载执行 |

### 4.3 权限模型

```
-rwxr-xr-x  user  wheel  /bin/ls.inim
-rw-------  user  user   /home/user/secret.txt
```

支持 `chmod`、`chown`、用户/组、root 权限。

## 五、Eidos 对象系统

### 5.1 核心语法

```python
eidos Monster {
    name = "Monster"
    hp = 100
    attack = 10
    
    take_damage(n) {
        hp -= n
        die() if hp <= 0
    }
    
    _die() {
        say name + " 死了"
    }
}

m = Monster("龙", 500)
```

### 5.2 特性一览

| 特性 | 语法 | 说明 |
|---|---|---|
| 属性即构造 | `name = "Monster"` | 自动生成构造参数、getter/setter |
| 继承 | `eidos Boss: Monster` | 单继承 |
| Mixin | `eidos Dragon: Monster + Flying` | 多重继承 |
| 运算符重载 | `+(v) -> ...` | 极简语法 |
| 热修改 | 重新 `eidos` 定义 | 所有实例立即生效 |
| 宇宙变换 | `verse_mapping A -> B when v1 -> v2` | 穿越时自动变换 |
| 不变量 | `invariant { ... }` | 自动检查修正 |
| 线程绑定 | `on m { ... }` | 自动绑定实例 |

## 六、安全架构

### 6.1 数据保护层级

| 级别 | 保护方式 | 性能开销 |
|---|---|---|
| L0 | 无保护（UI 文本） | 0 |
| L1 | 混淆（显示数值） | <0.001ms/帧 |
| L2 | 加密 + 动态密钥（金币/装备） | <0.02ms/帧 |
| L3 | 服务器权威（核心资产） | <0.1ms/帧 |

### 6.2 密钥生命周期

```
生成（多源熵）→ 分发 → 使用 → 轮换（20-40秒随机）→ 销毁
```

### 6.3 反外挂

| 威胁 | 防护 |
|---|---|
| 内存读取 | 加密 + 混淆 + GC 移动 |
| 内存篡改 | 服务器权威 + 校验 |
| DMA 外挂 | 密钥轮换 + 蜜罐 + 数据不可理解 |
| ML 破解 | 快速轮换 + 多维度混淆 + 不可微变换 |

### 6.4 进程隔离

```
isolate_run(script, timeout, "--safe --low-config")
```

崩溃不影响父进程，资源配额强制。

## 七、桌面即世界

### 7.1 桌面层

桌面是 Infiverse 的主层级 (0,0)：

- 图标 = 世界中的实体
- 文件夹 = 可进入的区块
- 窗口 = 通向其他层级的传送门
- 程序 = 其他 Verse 的入口

### 7.2 交互模式

```
桌面空间 → 走向文件夹 → 进入区块 → 走向程序 → 开启传送门 → 进入宇宙
```

### 7.3 协作

好友通过 `verse://<hub>/desktop/<user-id>` 链接进入你的桌面层级：

- 访客模式：只读，可走动观看
- 协作者：可编辑文件、移动图标
- 共同拥有者：完全控制

## 九、热修改系统

### 9.1 热修改层级

| 层级 | 修改对象 | 生效时间 |
|---|---|---|
| 脚本层 | .im/.inim 文件 | 下次调用 |
| Eidos 层 | 形态定义 | 立即（所有实例） |
| 内置函数层 | 运行时覆盖 | 立即 |
| 模组层 | DLL/SO 模组 | 重新加载 |
| 进程层 | 运行中的进程 | 接管迁移 |
| VM 层 | VM 状态 | 快照恢复 |
| 引擎层 | exe 本身 | 自我更新 |

### 9.2 安全网

所有热修改失败的最坏结果：Inim OS 进程崩溃 → Windows/Linux 显示错误 → 重启 Inim OS → 从快照恢复。

**母操作系统是永远的安全网。**

## 十一、与 Infiverse 的关系

```
Infiverse 多元宇宙
    ↓ 宇宙协议
Inim OS（每个节点的操作系统）
    ↓ 运行
Verse 隔离进程（每个宇宙）
    ↓ 法则
Eidos 对象（每个存在）
```

Inim OS 是 Infiverse 的**物理载体**。每个运行 Inim OS 的节点，都是多元宇宙中的一个物理服务器。节点之间通过 CRP 网络互联，形成去中心化的宇宙基础设施。

## 结语

**Inim OS 不是 Windows 的替代品，也不是 Linux 的竞争者。它是为 Infiverse 多元宇宙而生的一种新型操作系统。**

它的核心是一个 220KB 的不变 VM。它的灵魂是 Eidos——一个为多宇宙设计的对象系统。它的能力来自热修改——永远不需要重启。它的安全来自母操作系统兜底——大胆实验，不怕失败。它的未来是裸机——从用户态走向独立。

而它存在的意义，是让每一个宇宙的创造者，都能专注于创造本身，而不是纠结于操作系统、安全、兼容性这些底层问题。

**Inim OS 是宇宙的容器。Inimerse 是容器的材料。Infiverse 是容器中的星辰大海。**
