# 前沿能力分层路线图

`future/前沿.md` 描述的是长期研究方向。本文件将其拆成可验证的工程阶段，不改变 v0.3 的稳定性承诺。

## v0.4：可观测性与实验接口

- 确定性随机源接口：显式种子、可记录调用序号，保留现有 `random` 兼容行为。
- 事件日志基础格式：时间戳、来源、Verse ID、载荷摘要和版本号；作为 `say.ai`、SPI 和调试器的共同事件格式。
- 快照实验 API：只读 VM 状态摘要和增量变量，不承诺完整世界恢复。
- 概率值先以普通数据结构和采样 API 实现，不引入新的语法或隐式随机状态。

## v1.x：可重放与可逆操作

- 全息记录：初始快照、输入、随机种子、网络消息和帧边界；二进制日志带校验和版本迁移。
- 重放工具：暂停、倍速、定位和差异诊断；先支持 headless，再接入桌面工作台。
- 可逆事务：为字段写入、集合变更、实体创建/销毁提供逆操作日志；外部 I/O 默认不可逆并需要显式边界。
- 快照与逆日志组合，设置内存上限、截断策略和崩溃恢复规则。

## v2.x：受约束的高级语言能力

- 概率编程：声明式分布、采样和可复现实验种子；推理算法通过模块 API 提供。
- 计算表达式/工作流组合子：先以库和宏实现，稳定后再进入语法规范。
- 线性资源检查：文件、socket、权限令牌等句柄支持静态使用次数分析和运行时兜底。
- 程序合成：只允许生成经过 lint、权限检查和沙盒验证的 `.im`，禁止直接覆盖源文件。

## v3.x：证明与多状态计算研究

- 证明携带代码：先验证有限不变量和集合约束，失败时回退沙盒，不允许静默放行。
- 量子启发叠加：作为显式的加权候选值容器，不宣称量子计算能力；定义复制、测量和资源上限。
- 与 v3.1 集合化类型系统、ABI、`.vverse` 签名和审计日志统一版本规则。

## 非目标与约束

- 不在 v0.x 引入隐式随机、隐式回滚或改变现有脚本的数值语义。
- 所有记录格式必须可校验、可限额、可丢弃，不能阻塞 VM 主线程。
- 研究性语法先通过库/宏/实验开关验证，至少经过一个稳定版本后再冻结语法。
