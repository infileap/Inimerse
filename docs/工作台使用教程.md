# Infiverse 工作台使用教程
> **核对提示（2026-08-16）**：本文件为设计/规范文档，实现状态可能已变化；权威总览以 docs/API_REFERENCE.md 为准。


> 适用版本:workbench.im v3(迷你 IDE)
> 启动方式:双击桌面快捷方式,或命令行 `inimerse.exe workbench.im`

---

## 一、界面布局

工作台是一个 920x620 的窗口,分五个区域:

```
┌──────────────────────────────────────────────────────┐
│ Infiverse 工作台                        (窗口标题栏)  │
├────────┬──────────────────┬───────────────────────────┤
│ 创建项目 │ 文件列表:          │ 编辑区(可改,点保存写回):  │
│ 打包    │  (当前目录 .im 脚本,│                           │
│ 打开    │   点击选中,前15行)  │                           │
│ 开服    │                  │   (脚本源码,可直接编辑)    │
│ 分享    │                  │                           │
│ 下载    │                  │                           │
│ 运行    │                  │                           │
│ 刷新    │                  │                           │
│ 保存    │                  │                           │
├────────┴──────────────────┴───────────────────────────┤
│ 日志: (操作记录,滚动查看)                               │
├──────────────────────────────────────────────────────┤
│ 状态: 操作数 N | 文件 M | 编辑: xxx.im                 │
└──────────────────────────────────────────────────────┘
```

- **左侧按钮列**:9 个功能按钮(x=20~150)
- **文件列表**:当前目录(工作台所在目录)下所有 `.im` 脚本,最多显示前 15 个
- **编辑区**:点击文件后显示源码,可直接修改
- **日志区**:所有操作记录
- **状态行**:操作计数、文件总数、当前编辑的文件名

## 二、按钮功能详解

| 按钮 | 功能 | 说明 |
|---|---|---|
| 创建项目 | `mkdir("projects")` | 在工作台目录创建 projects/ 文件夹 |
| 打包 | 打包 demo 项目 | 把 `projects/demo` 打包成 `projects/demo.vverse`(Verse 宇宙包) |
| 打开 | 打开示例宇宙 | `verse_open("verse://local/projects/demo.vverse")`,进入示例宇宙 |
| 开服 | 打包并开启服务器 | 打包 `projects/host` 并打开,用于多人联机(本机当服务器) |
| 分享 | 分享链接 | 生成分享链接(示例地址 hub.example.com:8080,可自行改脚本) |
| 下载 | 拉取示例宇宙 | 打开示例宇宙(与"打开"相同入口) |
| 运行 | **运行选中脚本** | 先点击文件列表选中一个 .im,再点此按钮,会用 `start` 另开窗口运行 |
| 刷新 | 重新加载文件列表 | 新建/删除了 .im 文件后点一下 |
| 保存 | **保存当前编辑** | 把编辑区内容写回当前文件(GBK 原样,不会乱码) |

> 所有操作结果都会显示在日志区,如 `[pack] demo.vverse 已生成`、`[save] xxx.im ret=1`。

## 三、编辑脚本流程(核心)

1. **打开文件**:点击文件列表中的脚本(如 `verse_kernel.im`),源码会加载到右侧编辑区,状态行显示 `编辑: verse_kernel.im`
2. **编辑**:直接在编辑区修改
   - 支持中文输入(输入法可用)
   - 方向键移动光标、Home/End 行首行尾、回车换行、退格/删除
   - 滚轮上下滚动
   - 点击任意位置定位光标
3. **保存**:点左侧"保存"按钮(第 9 个),日志显示 `[save] xxx.im ret=1` 即写回成功
   - 保存是**手动**的,不会自动写盘——改完记得点保存
   - 文件以 GBK 编码原样写回,中文不会乱

> [注意] 保存会**直接覆盖原文件**。想试改的话,先在工作台外面备份一份。

## 四、一键运行

1. 在文件列表点击想运行的脚本(比如 `gui_ctrl_test.im`)
2. 点"运行"按钮
3. 会弹出**新窗口**运行该脚本(原工作台不关闭、不阻塞)

- 运行的是脚本所在目录的同名 `inimerse.exe`
- 想停止运行中的程序:直接关掉它的窗口即可
- 如果运行后没反应,看日志区 `[run]` 提示是否"未选中文件"

## 五、Verse 宇宙操作(打包 / 开服 / 分享)

工作台围绕 projects/ 目录管理两个示例项目:

- **demo**:普通游戏项目(单人)
- **host**:服务器项目(联机用)

常用流程:

**发布自己的项目**
1. 把脚本放进 `projects/demo/`(或修改工作台脚本里的路径)
2. 点"打包"→ 生成 `demo.vverse`
3. 点"打开"→ 进入该宇宙

**开服联机**
1. 点"开服"→ 自动打包 host 并打开(本机成为服务器)
2. 把"分享"得到的链接发给朋友
3. 朋友在工作台点"下载"即可进入

> 分享地址目前是示例地址 `hub.example.com:8080`,需要换成你自己的 Hub 服务地址(改 workbench.im 里 `verse_share` 那一行)。

## 六、常见问题

**Q1:文件列表是空的?**
- 确认当前目录下有没有 .im 文件(工作台只列 .im)
- 点"刷新"按钮重新加载
- 文件超过 15 个只显示前 15 个(可改脚本里的 `i < 15`)

**Q2:编辑区中文变乱码?**
- 引擎按 GBK 解析脚本;工作台读写都是 GBK 原样
- 如果乱码,可能是该文件本身是 UTF-8(用记事本另存为 ANSI/GBK 后,在工作台里重新打开)

**Q3:点"运行"没反应?**
- 先确认文件列表里选中了脚本(选中行有 `>` 标记,状态行显示文件名)
- **控制台自动隐藏**:启动后黑窗口自动消失;调试时在脚本里调 `gui_console(1)` 恢复
- 运行是另开窗口,看任务栏有没有新窗口
- 如果脚本本身有错,新窗口里会显示错误信息

**Q4:关不掉工作台?**
- 点窗口右上角 X 即可退出(WM_CLOSE 已接入)

**Q5:想改窗口大小/布局?**
- 修改 workbench.im 顶部:第 1 行 `gui_stage(920, 620)` 改尺寸
- 各区域坐标(按钮/列表/编辑区/日志)都在脚本前部,按注释调整

## 七、进阶:定制工作台

工作台本身就是一个 Inimerse 脚本,完全可以自己改:

- 加按钮:往 `btn_txt` / `btn_y` 数组加一项,再在 `while true` 的点击判断里加 `if btn_hit(N) { ... }`
- 改打包路径:改"打包/开服"按钮里的 `verse_pack("projects/demo", ...)`
- 改分享地址:改 `verse_share("demo", "hub.example.com:8080")`
- 加自动保存:在 `while true` 循环里定时调用 `save_file()`

改完记得点"保存",然后重新启动工作台生效。
