# v0.6 决定点：判定点的【独立判定 / 委托】分栏

**这一栏要答的问题（判据逐字，`exact-otter` 派单）：**

> **一个决定点的【数】，只有在你说了它是不是独立判定之后才算量过 —— 因为一个把答案交给别人的点，不会与任何人分歧，而它在计数里与一个独立判定完全相同。**

**本文件是 [`docs/streams/v06-decision-points.md`](v06-decision-points.md) 的增补，不是替换。** 那一件是**记录**（它的全部读数取自 `f6e22f5`，它的结论一条都不动）；本件是**今天的读数**（`9f3761e`）。

**观测点**：本文件全部读数取自 **`9f3761e80838a4a250535908a4d9aa7565f05494`**。开工与收工各跑一次 `git rev-parse HEAD`，两次同值 —— 这是这一族里唯一一个能证明「我读的那棵树没动」的动作。

**两套行号并存，两个都留：**

| 列 | 它是什么 |
| --- | --- |
| `f6e22f5` | 主清单写下的那个号。**本文件逐号在原树上复核过，22/22 全中**（复核命令见 §4）。它是**记录**。 |
| `9f3761e` | 今天这条命令量出来的号。它是**读数**。 |

★ 删掉任何一个，都会让「它漂过没有」变成不可判。

**判据（本文件用的定义，写在前面供第三方重判）：**

| 标记 | 判据 |
| --- | --- |
| **独立判定** | 它的代码里含有**决定那个可观察答案的规则**（真值规则 / 特判 / 常量）。 |
| **委托** | 它把答案交给**别处**产生（宿主的运算符 / VM 的 opcode / 生成的 C 的布尔运算符 / wasm 指令）。 |
| **混合** | 答案有两半，而两半的归属不同 —— 按**【真值判定交给谁】**与**【结果交给谁】**分开判。 |
| **上下文保证** | 规则是独立写的，而**调用它的位置保证它不可能产生分歧** —— 既不需要同步，也不需要处置。 |

★ 后三类在计数里与第一类长得一样，而处置各不相同：**独立要同步，委托不用管，上下文保证两样都不用。**
