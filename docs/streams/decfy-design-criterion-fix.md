## 2. 判定（三条分开写，各自成立与否不同）

### 2.1 「本文档 `[实测]` 栏为『无』」今天为假 —— **成立**

`022d002` 那唯一一行实测栏，逐字是：

```
| **[实测]（本会话执行命令）** | **无。** 本会话未构建、未跑 tools/im_diff_fuzz.py、未跑任何执行通道。 |
```

今天实测栏 **16 行**，且「未构建」那行**已不存在**（`grep -c '本会话未构建'` 在 `6fd1b92` 起即为 **0**）。[obs: d0ad1c1]

### 2.2 「§0.5 是 `ec3008f` 补写的」—— **成立**

`ec3008f` 引入 `## 0.5 落地现状`（`022d002` 里该节不存在，`grep -c '^## 0.5'` 由 **0** 变 **1**）。[obs: ec3008f]

### 2.3 ★「`ec3008f` 起新增 §0.5 与 18 行 `[实测]`」—— **不成立；照抄会引入一个新错**

`ec3008f` 那一刻 **`rows` 仍是 1、内容仍是「无」**（文件从 249 到 272 行，增的是 §0.5 的落地现状文字，**没有一行实测**）。实测行是**下一笔** `6fd1b92` 才长出来的（`rows` 8），一路到 `276982e` 的 16。

⇒ 把「§0.5」与「18 行实测」并成「`ec3008f` 起新增」，**就是把两个不同提交的功算到一笔上** —— 而这个形状正是这一段要治的那类东西（一个 ref 背了两件事）。

### 2.4 「文档后来长出了实测，不是当初造假」—— **成立，且可逐笔追**

`rows` **只在下面八个提交上变化**（其余提交不动它），一格一格量出来的：

| 提交 | `rows` |
| --- | --- |

**单调不回落**（逐对比较，8/8 成立），且每一笔都加在 §0.5 之后。⇒ 是增长，不是追改。[obs: d0ad1c1]

枚举命令（逐字可复跑，**不要手抄上表**）：

```bash
for c in $(git log --format=%h --reverse -- docs/DECFY_DESIGN.md); do
```
