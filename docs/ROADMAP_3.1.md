# Inimerse v3.1：集合化类型系统

集合化是长期语言演进项目，不纳入 v0.3–v0.6 的交付承诺。v3.1 之前只维护 `N`、`Z`、`Z+`、`Z-`、`R`、区间和有限集合的兼容行为。

## 目标

- 以集合关系统一类型、约束、精化类型与 Verse 映射。
- 引入谓词集合、命名集合、集合类型别名和静态子集证明。
- 在无法证明时自动插入运行时检查，并保留解释器回退路径。

## 范围

- `in`：成员与子集判断；必要时增加显式 `subset` 别名。
- `+` / `*` / `-`：并集、交集、差集，覆盖有限集合、区间和命名集合。
- `be`：编译期证明、运行时检查、错误定位和约束传播。
- 谓词集合：`{x in Z | x > 0}`，支持常量折叠与缓存。
- 集合类型别名：`type Positive = Z+`。
- 类型集合与 Eidos 属性、前置/后置条件、Verse 映射的统一规则。
- 大集合的数据结构：哈希索引、位图、区间压缩和不可变结构共享。

### 表示优化与数值集合

- `Z` 保持数学上的无限整数集合；运行时增加 BigInt 表示，并对机器字长内的值使用小整数（small-int）快速路径。
- 集合交集形成的有限范围可触发表示窄化：`Z * [0~255]` 使用 `u8`，`Z * [-32768~32767]` 使用 `i16`。无法证明时回退到通用整数表示并插入检查。
- 有限集合字面量（如 `A = 1, 2, "A", "S"`）编译为稳定枚举 ID；局部变量和静态数组按最小字节宽度存储，动态容器与跨模块边界保留 boxed `Value`。
- 支持用户定义范围类型，例如 `type byte = Z * [0~255]`、`type port = Z * [0~65535]`，并定义窄化、扩大、溢出和显式转换规则。
- `FloatN`/谓词小数集合优先采用定点整数或 Decimal 表示，避免二进制浮点误差；序列化格式必须保留精度和集合约束。
- BigInt、窄化整数、枚举值在模块 ABI、`.vverse` 序列化和调试器中保持可逆映射，禁止把内部编号泄露为用户值。

## 非目标

- v3.1 之前不删除 `Float1`–`Float9`/`float1`–`float9`。
- 不在没有规范和迁移工具的情况下改变 `in` 的既有语义。
- 不把任意不可判定谓词伪装成编译期类型证明。

## 验收标准

1. 规范、编译器、VM 和 API 文档使用同一套集合语义。
2. 有限集合、区间、命名集合的并/交/差运算具备完整测试矩阵。
3. 静态证明失败时产生可定位的运行时检查，而不是静默放宽约束。
4. 集合运算在基准数据上有明确内存和延迟上限。
5. v0.x 脚本无需修改即可运行，或提供自动迁移工具和诊断报告。
6. `byte`/枚举/范围类型通过内存占用基准；BigInt 和 Decimal 通过边界、溢出、精度及 ABI 回归测试。
