# V0.4 数值模型草案

## 现状

当前 lexer/parser 将带小数的字面量交给 `strtod`，VM 主要使用 IEEE-754 `double`。
这适合图形和一般计算，但不能保证长小数或大整数运算的精确性。

## 集合论式数值塔

把运行时数值定义为不相交并集：

```text
Number = Z ∪ Q ∪ D ∪ F
```

- `Z`：任意精度整数（BigInt）。
- `Q`：有理数 `(p, q)`，其中 `p ∈ Z`、`q ∈ Z\{0}`，始终约分且 `q > 0`。
- `D`：任意精度十进制定点/科学计数数，保存 `significand × 10^exponent`，不转成二进制浮点。
- `F`：IEEE-754 浮点，仅用于显式近似计算、图形 API 或性能优先路径。

嵌入关系为 `Z ↪ Q`；有限十进制可嵌入 `Q`，但保留 `D` 的词法和显示精度。默认字面量不应静默降级到 `F`。

## 运算规则

1. `Z op Z` 保持 `Z`（溢出自动提升为 BigInt）。
2. `Z/Q` 混合运算提升到 `Q`，加减乘除保持精确；除零是运行时错误。
3. `D` 与 `Z/Q` 运算先提升到任意精度十进制或有理数，禁止经过 `double` 中转。
4. 只有显式 `float(x)`、`approx(x)` 或需要 `F` 的外部 API 才允许进入 `F`。
5. 比较和集合去重按规范化后的数学值进行：`1 == 1/1 == 1.0`，哈希必须一致。

## 实现顺序

1. 保留数字 token 原文，在编译常量池中增加 decimal/bigint 文本入口。
2. 引入 `Num` tagged union 和 BigInt/Rational 最小实现；小整数继续内联以保持性能。
3. 改造四则运算、比较、序列化和集合哈希，补充长小数/大整数回归。
4. 最后接入可选 `F` 快路径，并用随机生成的 `Q` 运算对照测试精确路径。

验收标准：`0.1 + 0.2` 的精确结果保持十进制语义；100 位小数和超过 64 位整数在加减乘除、比较、集合去重及序列化后不丢失有效信息。
