关于

这个站点是 Inimerse / Infiverse 的对外门面：能玩的东西、能看的演示、能用的工具。

内容以仓库为准

站点用的是免费二级域名 infiverse.localhost.cc，它不属于我们—— 平台随时可能回收。所以真正的 canonical 副本是 Git 仓库里的 website/ 目录：域名没了，内容一行不丢，换个域名重新指一次就回来了。

这个域名不适合做的事

不要做原因
拿它发邮件免费二级域名不适合作为邮件身份，极易被判垃圾
把它当唯一入口域名不属于你，回收即全损；仓库才是底本
用它做需要长期信誉的事域名带 localhost 字样，部分企业 DNS 过滤器与 SSRF 校验会误杀
指望广告变现免费二级域名基本接不到主流广告联盟

反正该做：尽早买一个真域名，把这个站 301 过去；现在的建设方式（相对路径、无构建、内容在 Git） 保证了将来搬家只是一次复制。

技术约束（建设时就定下的）

  • 相对路径：整站可以被放在任意子目录下，包括 B站 Toy 的 /toy/<slug>/。
  • 零依赖零构建：没有打包步骤，没有 CDN，没有外部字体；双击 index.html 就能看。
  • 数据内联为 JS：不用 fetch 读 JSON，所以本地打开和线上托管表现一致。
