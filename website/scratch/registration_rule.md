# ㉓ 把「越界」从布尔变成分布（协调者 m01044 的派件）

# ㉔ 把「不适用」从一句判词变成一个可执行的定义（★ 判据 —— 先写下来，再跑）

## 0. 为什么这一件是必要的

★ 我手上有**三条常驻红**。上一件我自己写过一句话：
> 「每一个细组必须完整落在某个粗组里」对残余类按构造为假，任何步数上限都改不了。

★★★ **那句话就是「不适用」的定义 —— 只是它当时没有那个名字。**
★ 而三条常驻红里，如果有的不是红、是**尺子对那个对象不适用**，那么「守卫有 3 条红」这句话
就一直在把两种完全不同的东西记成一个数。

★★ 另一条车道（`noble-zephyr`）在另一个语料上看到的是同一件事的对偶：
**一个多档分类器缺了「不适用」这个出口时，那个出口里的东西会全部落进「其他」，而「其他」因此永远是最大的一档。**

## 1. 三条候选红（逐字，取自本件基线的守卫输出）

```
R1  ⑱ 验收③：留一法之后 N 必须非零（扣掉一行 ⇒ 少 1，不是变成 0）  ← 1 → 0（扣掉 :10808）
R2  ⑳ 验收③：每一个细组必须完整落在某个粗组里（一级是另一级的粗化）  ← 具名细组跨粗组的 = 0 个；残余类【（无细组）】= 5 行、跨 4 个粗组
R3  ㉑ 验收④：有界版下【不排除残余类】也必须为真（每一个细组完整落在某个粗组里）  ← 跨粗组的细组 = 1 个：（无细组）
```

## 2. ★★ 「不适用」的可执行定义（★ 不许用「读起来像」「本质上是」）

对每一条检查，定义两个从**代码与数据**算得出来的集合：

- ★ **输入集 `S(check)`** = 那条检查**实际求值过的那些对象**的集合 —— ★ 从它自己的源码里读出来（它 `map`/`filter` 了哪个数组）；
- ★ **范畴 `dom(check)`** = `S` 里**那条谓词有定义**的那些对象 —— ★ 一个对象属于 `dom`，当且仅当
  **它是由那根【匹配 `GRP_RE` 的行】产生的**（对 R2/R3）或**它带着自己的行号与据、可以被单独扣掉**（对 R1）。

★★★ 三个档，互斥且穷尽：

| 档 | 可执行判定 |
|---|---|
| ★ **真红** | `obj ∈ dom(check)` **且** `pred(obj) === false` —— ★ **谓词有值，值是 false** |
| ★ **不适用** | `obj ∈ S(check)` **且** `obj ∉ dom(check)` —— ★ **谓词无值（⊥），不是 false** |
| （对照档）**不适用被治好了** | 同一 `obj` 在另一棵树上 `∈ dom` ⇒ ★ 此时它落回【真红】 |

★★★ **一句话的分界：不适用 = 谓词无值；真红 = 谓词有值且为假。**
★ 而「无值」必须是**可算的**，不能是修辞 —— 所以每一条都要交出它自己的 `dom` 判定式。

## 3. ★ R2/R3 的成员判定式（★ 不引用哨兵常量）

★ **不许写成 `k !== RESID`** —— ★ 因为那**就是**那个常量本身，写出来是同义反复、不是测量。
★ 正确的写法是**回到产生它的那根线**：

```
⑳③ / ㉑④ 的 dom 判定：  producedByGroupLine(k) := 取 k 的第一行，回溯 fineAt / fineAtBounded，
                                                 ★ 返回的 .line !== null（★ 意义 =「找到了一根线」）
★ 「具名细组」⟺ .line !== null　　「残余类」⟺ .line === null 而 .stoppedAt 是一根 markdown 标题
```

★ 这个判定式**不提 `RESID` 一个字**，因此它可以被对照证伪。

## 4. ★ R1 的成员判定式

```
⑱③ 的 dom 判定：  removable(row) := row.n !== null && hasGround(row.text)
★ 即「这一行带着自己的行号与据、可以被单独扣掉」—— ★ 这正是留一法的定义域。
```
★ **我的预判（可被推翻）**：★ R1 是**真红** —— `N = 1` 时谓词**有值**（`false`），
★ 而它的可修性在于**分子太小**，不在于尺子。
★★ **若我要推翻它，我必须交出一个读数**（不是一句话）。

## 5. ★ ③ 要求的第二个区分：(a) 范畴错误 还是 (b) 射程外

| | 可执行判定 | 含义 |
|---|---|---|
| ★ **(a) 范畴错误** | `obj ∈ S` 且 `obj ∉ dom` | ★ **这个对象不是那个范畴的成员** |
| ★ **(b) 射程外** | `obj ∈ 那个范畴` 且 `obj ∉ S` | ★ **这个对象不在那把尺子的输入集里** |

★★ (b) 是可以**数出来**的：★ `docs/AUDIT.md`（钉住的那棵树 `4829766`）里有 **59** 根匹配 `GRP_RE` 的行
⇒ 那 59 个标签里，**有几个落在本检查的输入集里**？★ 差就是射程外。
★ 这个数**在本件的基线上就存在**，不需要对照 —— ★ 它是「这把尺子的射程」的读数，
和「这把尺子对自己的宾语适用不适用的」读数是**两个数**。
