# 「真登记」的判据 —— ★ 先写下，再跑

★ 这一份**只有判据，没有读数**。读数是**下一个 commit** 的事。
★ 这样「先写判据、再跑」这件事是**用 git 自己可核的**：
`git log --diff-filter=A -- website/scratch/registration_rule.md` 的那一笔，必须是跑它的那一笔的**父**。

## 一句话

★ **一条【登记】是台账这个制品在说它自己记了什么；一条【提及】是某个话题在台账里出现过。**

## 判据 v1（四条全中才算）

台账 `docs/AUDIT.md` 的一行 L 是节 S 的一条**真登记**，当且仅当：

1. **是这一节** —— L 含 S 族里 **≥2 个成员**，其中 **≥1 个是实体成员**（F2 反引号片段 / F3 文件名 / F4 ≥4 字连续汉字串）。
   ★ **泛成员不算数**：F1 标题与占位符 `(文件头/无节)` **不参与这一条**。
   ★ **今天无载荷（协调者裁定：不删，写进这里）**：这一条限制**在火集上什么都没做** ——
   红对照 B（允许泛成员）⇒ 全量**仍 1 条**、留一法**仍 0 条**。
   ★ **不删的理由**：它今天无载荷是因为它砍的对象**本来就不在族里** —— 明天族规则一改，它就会开始砍东西；
   **一条没有下限的判据会长出假阳性，而假阳性比无载荷更坏。**
   ★ 写在**这一份**里，不是写在报告里：**报告会被下一次读数覆盖，注释会跟着这条判据走。**
2. **在裁** —— L 含**裁定短语**：`已裁` / `已裁定` / `裁定` / `已决定` / `裁了` / `裁决` / `驳回` / `采纳`。
3. **是台账在说自己** —— L 含**台账自指词** `台账`。
4. **不是自指** —— L 不在 S 自己的行范围内。

# ㉒ 把残余类从「细组」里移出去（协调者 m01002 的派件）

## ★ 判据（文字 —— 写在做之前，见父提交）

★ **`（无细组）` 不是「细组这一级的一格」。** ★ 它是**「没有细组的那些行」的并集** ——
一个并集没有「落在哪个粗组里」这件事，所以 **④（「每一个细组必须完整落在某个粗组里」）
这句话的宾语如果是它，那么那句话在语法上就没有主语。**
★ 上一件量到的是：★ **这个假不是【尺子越界】造成的**（有界版与无界版在基线上逐格相同）。
★★ 本件把宾语换掉：**④ 的宾语只剩具名细组** —— ★ **先让那句话有主语，再问它真假。**

★ 三条派生处置：
1. ★ **残余类不许进 ④ 的宾语**；
2. ★ **它与具名细组的计数【并排印、不相加】** —— ★ 理由：**一个数如果由两个不同的计数对象相加而来，
   那么那个和会被读成一个【完备的分类】，而它不是一个分类**；
3. ★ **④ 改后的红/绿必须报出**；★ **若仍红，那条红是本件的新头条。**

## ★ 可证伪的形式

★ **预言六：改后，④ 在【基线上】转绿。**
★ 理由：基线的具名细组是 4 个（`丁组 · 谁裁的` 1 行、`戊组 · 一个会永远存在的差…` 1 行、
`戊组 · 分母从概念来…` 2 行、`己组 · 登记：十一条人裁定…` 2 行），★ 而上一件量到 **具名细组跨粗组 = 0 个**。

而上一件那句「具名细组跨粗组 = 0」就是错的。★ **照实报。**
