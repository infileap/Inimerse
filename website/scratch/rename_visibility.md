# 甲⁵ · 改名有没有落到读者眼前 —— 判据先行

**本文件是【判据】，不是【读数】。** 它先落盘、单独成一笔，**是读数那一笔的祖先**
（`git merge-base --is-ancestor <本笔> <读数笔>`）。读数落进同一棵树的后续一笔。

```
pwd    = /home/sakiko/inimerse/.worktrees/website-ledger-readat
读法   = 工作树文件（不是 git show <sha>:<path>）
被量的那笔 = c2a8d7a（② 改名 ＋ ③ 理由更正）
本笔的父   = c2a8d7a
```

---

## 一、exact-otter 的判据（本件的目的，署 exact-otter 名）

> **一个名字如果没有任何读者看见它，那么它在读者那一侧与「没有改名」同形。**

★ 这条是**本件存在的理由**：改名的效果不落在文件里，落在**读者那一侧**；而文件里改名成功、
读者那一侧一个字都没变，是**两件都成立**的事。

## 二、先报「载体是否存在」（动工前，本文件落盘时已实测）

「会被印出来」这句话必须先证明**印**这件事今天真的发生。今天的三个可能载体：

| 载体 | 存在吗 | 证据（本次实测） |
|---|---|---|
| ① 守卫的 stdout | **存在** | `node website/scratch/check_citations.js` ⇒ rc=1，**1169 行** |
| ② 渲染出的 DOM | **存在，但它的【文字】不进 stdout** | `node website/scratch/render_check.js` ⇒ rc=0，**只有 9 行**（它是断言器，不是打印机） |
| ③ 站点文件本身含这个名字 | **存在，但它不是「读者」的证据** | `grep -c 手抄对照清单` ⇒ `spec.js:1`／`site.js:2`／`check_citations.js:9` |

### ★★ 载体②是这一件的陷阱
`render_check.js` **只印 9 行**，DOM 里的文字**一行都不进它的输出**。⇒ 「渲染器跑了」不等于
「有人在输出里看见了那个名字」。**载体②要另造探针去 DOM 里读文字，不能拿 `render_check` 的
9 行当它被看见的证据。**

### ★★ 载体③不是读数
三个文件里出现这个名字，只说明**我自己写进去了**。★ 这正是本件要反对的那种「证据」：
**「文件里有这个名字」与「读者看见了它」是两个命题，而前者今天有 3 个 grep 命中，后者要另量。**

## 三、分母（★ 这是本件最要紧的一条，因为它是我上一次报错的）

**一处** = 本笔 diff 里**新增的、含新名字的行**，按 `(文件, 行号)` 计。
新名字 = `手抄对照清单` 或 `清单里有`。**命令**（可复算）：

```
git diff -U3 c65120e c2a8d7a -- website/ | awk '... /^\+/ && /手抄对照清单|清单里有/ ...'
```

**实测分母 = 13。**

### ★★★ 我上一次报的数是 12，而它是错的
我在给 exact-otter 的报告里写「改的位置：`spec.js`／`site.js:472`／`check_citations.js` **10 处**」，
并在这一件的口头摘要里说 **12 处**。**实测 13。**
⇒ **判据：一个从记忆里报出来的分母，与一个从 diff 里数出来的分母，在报告里同形；而
`git diff` 不会因为我的记忆而改数。** 本文件的分母以 **diff 实测的 13** 为准。

## 四、四档（互斥，和 = 13）

| 档 | 定义 | 怎么判 |
|---|---|---|
| **① 会被印出来** | 那个名字今天**出现在某一次真实运行的输出文字里**（守卫 stdout 的某一行，或渲染出的 DOM 的某个文本节点）。**必须给出那一行的行号**（DOM 就给哪个页、哪个元素、文本前缀） | 跑两把尺子，逐处去输出里找 |
| **② 只在注释里** | 那个名字在源码里，但**不在任何表达式的实参里**（被 `/* … */` 或 `//` 包住） | 看那一行是否在注释内 |
| **③ 只在文件头／说明文字里** | `.md` 或文件的头部块：**是给人读的文档，但不经由任何一次运行的输出** | 它不在 `.js` 的可执行路径上 |
| **④ 判不了** | 只有两种合法情形：**(a)** 我的尺子看不见那种形状；**(b)** 那个对象落在定义域之外。**其余一切「判不了」都等于【我没去读它】** | 写清是 (a) 还是 (b) |

★★ **档①与档③的区别不是「有没有人读」**（两种都有人读），是 **「它是被一次运行印出来的，还是被
我手写进一份文档的」**。⇒ **后者的读者只有去读那份文档的人；前者的读者是每一次跑那把尺子的人。**

## 五、两个反方向对照（跑之前写下，跑完照原文填）

### 对照 (a)：尺子看得见「被印出来」吗
喂一处**已知确实会被印出来**的字符串（例如表头里的 `在手抄对照清单里？`，它今天逐字出现在
守卫 stdout 的 `:1161`），尺子必须判 **①**；喂一处**已知只在注释里**的（例如 `:314` 那一行），
尺子必须判 **②**。★ 若两者判成同一档 ⇒ **尺子没有分辨力，整张表作废。**

### 对照 (b)：尺子会不会把「我写进去的」数成「被印出来的」
**载体③的 3 个 grep 命中必须判不进档①**（它们只是文件里有）。
⇒ 若尺子把「文件里出现」判成 ①，它量的是**我的写入**，不是**读者的看见**。
★ 本会话已裁定过的同族：**「建了」与「被用上了」是两个读数。**
