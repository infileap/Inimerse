## 第三节 ★★★ 头条：R4 从 1 变成 57，而它一直是 57

**第一次运行时 R4 = 1。** 修好一处字符串之后 **R4 = 57**。

### 缺陷逐字

判「这条规则命中了吗」的那个谓词写的是：

```

```


**`不在只读表` 与 `非只读` 不是同一个字符串。**

### 后果

⇒ **R4 挡下的每一处都在那个谓词上落空** ⇒ 它们**不在 ⑤ 里**。
⇒ 分母**只小了 56**，**不报错**，报告**逐项自洽**，**互斥和仍然对得上**。

⇒ ★★★ **判据 F15：一条规则的名字与它被匹配时用的那个字符串，如果不是同一个字符串，
那么这条规则挡下的每一处都会静默地落空 —— 而分母只会小一点，不会报错。**

★ **这与本项目里已发生过的同一族同族**：一条**按行里出现的关键词**排除的规则，
排除掉的是**那个词**、不是**那一行的角色**。

### 修法

判定**一律按规则的键**（`R0`–`R5`），**不按它的描述字符串**。
⇒ **修法是把「命中」写成结构化的事实，不是把两个字符串抄得一样。**
