# 辛⁷ 判据先行：把「Δ 的方向与符号」做成一张可复核的表

★ 本文件是**判据**，先落盘；读数是它的后代（`git merge-base --is-ancestor` 判，不眼看）。
★ 本件**只量不写**：一个受跟踪文件都不改。

---

## 第零节 对象与两个分母

★ **D0.1** **对象 = 「差 = N」形式的断言**，其中 `N` 是一个数，出现在**本车道的产物**里
（`website/scratch/*.md`，受跟踪），且它说的是**两个计数之间的差**。

★ **D0.2** ★★★ **本件必须同时报两个分母，并排、不许合**：
- **分母 P = 【行】数** —— `文件:行` 的唯一数（同一句话在不同文件/不同行出现算多处）；
- **分母 Q = 【断言】数** —— 把**同一句话的多份副本**（源码里的一次 ＋ 每次运行输出的一次）算**一处**。

★ **D0.3** ★★★ **理由**：留档（`*_transcript.md`）里同一句话会出现 **1 + 运行次数** 次
（一次是探针源码里的 `say(...)`，其余是每次运行的输出）。
⇒ **「一共有几处」这个问题的答案取决于「处」是按【行】数还是按【断言】数。**
★ 本件**上报口径 = Q（断言）**，**P 并排印出**。

★ **D0.4** **副本的判定**：两行是同一断言，当且仅当**去掉行首空白与行号前缀后的正文逐字相同**。
★ 若两行正文相同而**不在同一个文件**，仍算**同一断言**（同一句话被留档复制到另一份产物里）。

---

## 第一节 逐处必须印的六样（判据 D1）

★ **D1.1** 逐处印：
1. **文件名**；2. **行号**；3. **逐字那一句**；
4. **是【哪一对口径】**（没写就印「未写」）；5. **符号**；6. **那个数今天重算的值**。

★ **D1.2** ★★★ **「哪一对」的判定只看那句话本身**：
- 句子里出现「**X 与 Y 的差**」或「**X → Y**」或「**X 相对 Y**」⇒ **写了**，取 `(X, Y)`；
- 只写「差 = N」「差是 N」「差为 N」而**没有任何两个名字**⇒ **未写**。
★ **D1.3** ★★ **不许从上下文补出那一对** —— 若补了，那处就变成「写了」，而**它自己没写**。

★ **D1.4** **符号** = 那句话里那个数**逐字的符号**（`+`／`−`／无符号）。
★ **D1.5** **重算** = 用**与庚⁷ 逐字相同的提取器**今天算出的值：
- 口径① = 不认引号；口径② = 认引号；口径③ = 认引号且双引号里 `$`／反引号算。
- `①→②` = `|① \ ②|`；`②→③` = `|③ \ ②|`；`①→③` = `|① \ ③|`。

## 第二节 必须逐字回答的四个问题（判据 D2）

★ **D2.1** **一共有几处？**（给数，Q 与 P 并排）
★ **D2.2** **其中有几处，那一句里没有写【哪一对】？**（给数，**逐处点名**）
★ **D2.3** **符号为负的有几处？**（给数）
★ **D2.4** ★★★ **今天重算之后，有几处的值变了？**（给数，**逐处给旧值 → 新值**）
★ **D2.5** ★★ **「值变了」必须区分两种**：
  (a) **那个数本身**变了（重算 ≠ 逐字写的那个数）；
  (b) **那个数没变，而它指的对象变了**（分母动了）。
  ★ 本件只判 (a)，**并把 (b) 单列**。

## 第三节 四档（判据 D3）

| 档 | 判词 |
|---|---|
| ① | **写了哪一对，且重算相同** |
| ② | **写了哪一对，但重算不同** |
| ③ | **没写哪一对** |
| ④ | **判不出**（必须带理由，且理由必须是「那把尺子看不见这个形状」或「这个对象在定义域之外」） |

★ **D3.1** ★★★ **和必须 = 分母 Q ✓。**
★ **D3.2** ★★★ **④ 不许装「我没有去读它」** —— 那是第五档，必须单列（戊⁷ 的 F5.3）。
★ **D3.3** ★★ **③ 那一档里的处，重算值照样要给** —— 「没写哪一对」**不等于**「那个数无法核对」。

## 第四节 对照（判据 D4）

★ **D4.1** 两个**反方向**对照：
- **(a) 一处已知写了哪一对** —— 必须落 ① 或 ②；
- **(b) 一处已知没写哪一对** —— 必须落 ③。
★ **D4.2** ★★★ **红就照实报红** —— 不许把 (a) 换一个名字当成 (b)。

★ **D4.3** **空集对照**：把对象取成空集 ⇒ 四档全 0，和 = 0 = 分母 ✓。
★ 而 **「空集 ⇒ 和 = 0」与「对象里一处都没有」在输出上同形** ⇒ **必须把分母一起印**。

## 第五节 诚实边界（判据 D5）

★ **D5.1** **只读不写** —— 一个受跟踪文件都不改。
★ **D5.2** ★★★ **逐字回答：本件有没有跑任何文档里的命令？** 有 ⇒ 逐条列出；没有 ⇒ 逐字写「没有」。
★ **D5.3** **逐个按名字 `git add`**（不许 `git add -A`／`git add .`）；报告里印**跑后** `git status --porcelain` 的**逐字输出**。
★ **D5.4** 四件套：`pwd` ／ `git rev-parse HEAD` ／ 读法 ／ 原始输出 ＋ `count(base..HEAD)`；
`git diff --stat <分支点> HEAD -- docs/` 必须**空**（**三参形式，第一参必须是本分支点，不是 `origin/main`**）。
★ **D5.5** ★★★ **`origin/main` 不是本会话 HEAD 的祖先**（癸⁶ 与庚⁷ 各命中一次）⇒
**任何 `git diff A B -- <path>` 的第一参都必须先过 `git merge-base --is-ancestor`。**
★ **D5.6** 判据文件必须先落盘，且是读数文件的**祖先**。
