## 三、★★★ 头条：`:254` 是第三种，不是「不印」
把 `:261` 真的弄红（`data/spec.js` 不导出 `INFIVERSE_SPEC`）之后：**rc=1，输出只有 17 行，FAIL = 0 行**，逐字是：
```
fatal: invalid object name 'undefined'.
…/check_citations.js:2749
  specs.push({ what: '本页的主观测点 spec.js.ref', ref: S.ref, file: null });
                                                   ^
TypeError: Cannot read properties of undefined (reading 'ref')
```
⇒ **`:261` 在【它红的方向上】永远走不到判词那一行**：`S` 一假，守卫在 **`:2749`** 就崩（比 `:261` 晚 2488 行、比印判词那一行更早），**进程直接死，报告从来没被生成**。
⇒ **它绿的时候看起来完全正常**（今天就是这样），**它红的时候连一条 FAIL 都不存在。**

★★★ **判据（署我名）：一条 check 可以有一个【在它红的方向上永远到不了的判词】—— 红不是「印出一行」，而是「把仪器弄死」。于是「这条 check 保护了什么」在它绿的那一侧无法判断，在红的那一侧也不存在判词。**
