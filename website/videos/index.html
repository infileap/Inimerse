实机演示

引擎与桌面端的真实运行画面。每条记录都带录制时的代码版本（git ref）， 所以隔一段时间回来看，仍然知道当时跑的是哪一版。

B站 账号 源码（看录制时的版本）

记录是唯一入口。 站点只按记录渲染：没有 id / 标题 / BV 号 / 时长 / 分辨率 / 封面 / 简介 / ref + 日期 这一组字段， 视频就不会出现在这里。未投稿的写「未投稿」，不要留空——留空和忘记投稿看起来是一样的。

交付要求（给录制那边）

按这份参数交付，接上就是一步，不用再来一轮。

项要求
封面比例 / 分辨率横屏 16:9，最低 1280×720，建议 1920×1080；JPG 或 WebP，≤ 300 KB
封面文件名<id>.jpg，与记录里的 id 一致
竖屏9:16，1080×1920；单页最多 1 条竖屏，不与横屏混排同一行
内嵌还是外链以 B站 外链为主（封面 + 跳转按钮），站内播放为可选的点击后加载
单页放几个最多 12 条；第 1 条可标 featured 占整行
横竖屏默认横屏；竖屏在记录里写 orientation: "portrait"
时长 / 分辨率时长形如 03:42，分辨率形如 1920x1080
录制版本ref = 录制时的 git rev-parse HEAD 完整 40 位 + 录制日期
